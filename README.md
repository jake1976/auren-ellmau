# AUREN Owner Presentation

A confidential, single-page owner presentation for the AUREN residence, prepared by IMPAC Project Marketing (German/English, switchable in the page). It is a static HTML site with no build step.

## Technologies
- Plain HTML, CSS and vanilla JavaScript (all inline in `public/index.html`)
- Google Fonts (Marcellus, Newsreader, Manrope)
- Netlify static hosting (`_headers` sets `noindex` and referrer policy)

## Running locally
Serve the `public/` folder with any static server, for example:

```bash
npx serve public
# or
netlify dev --port 8889
```
